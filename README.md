# Student Grade Tracker

## 📌 Project Overview

Student Grade Tracker is a Java console-based application developed as part of the CodeAlpha Java Programming Internship.

The application allows users to enter student names and their scores and generates a summary report containing the average, highest, and lowest scores.

## 🎯 Objectives

- Input and manage student grades
- Store student information using ArrayList
- Calculate the average score
- Find the highest score
- Find the lowest score
- Display a summary report

## 🛠️ Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming
- Console Interface

## ⚙️ Features

1. Enter the number of students
2. Enter student names and scores
3. Validate scores between 0 and 100
4. Store student data using ArrayList
5. Calculate average score
6. Find highest score and student
7. Find lowest score and student
8. Display a formatted summary report
